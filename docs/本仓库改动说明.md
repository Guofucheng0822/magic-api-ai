# 相对官方 2.2.2 dev 的改动

本分支从官方 `dev`（2.2.2）拉出。下面是在官方 AI 插件和数据源能力上增加的内容，供其他项目接入时对照。

## 能做什么

1. **在控制台里直接查多个库。** 对话按当前已加载的库、表和字段写只读脚本并执行，结果展示在对话里。写入语句不会执行。
2. **结果和文档可以导出。** 查询结果导出 CSV，单次最多 2 万条。回复内容是接口文档时，可导出 Markdown。
3. **确认后的查询可以变成接口。** 在面板里填写名称、路径、方法和参数后保存为新接口，不覆盖当前打开的接口。脚本以文件形式存放，保存后热更新。
4. **同一套插件可以接到其他项目。** AI、ClickHouse、Redis、Doris、SelectDB 都是独立插件。项目只启用自己已经配置的数据源。

## 数据源

| 插件 | 脚本写法 | 何时可用 |
| :--- | :--- | :--- |
| 默认库 | `db.select` / `db.selectOne` | 项目原有数据源 |
| ClickHouse | `db.clickhouse.select` | 配置了 `clickhouse.address` |
| Redis | `redis.get`、`redis.hget` 等只读命令 | 已有 Redis。Redisson 下不开放写入 |
| Doris | `db.doris.select` | 配置了 `doris.address`，协议为 MySQL |
| SelectDB | `db.selectdb.select` | 配置了 `selectdb.address`，协议为 MySQL |

地址为空时，Doris 和 SelectDB 不注册，控制台数据源树里也不会出现。ClickHouse 和 Redis 在本项目的编辑器树中保留入口。

## AI 对话

- 每次提问带上已加载的库、表、字段和注释。用户用业务说法提问时，由模型自己对应表和字段。
- 生成后检查 magic-script 常见写错，例如 `let`、箭头函数、三引号、比较符被写成转义符。不合规则自动重写一次。
- 运行失败时，对外接口仍返回统一的内部错误。助手根据运行日志里的错误和 SQL 说明原因，由人确认后再替换脚本。
- 会话历史保存在当前浏览器的 `localStorage`，可改名、删除，最多 30 条。换浏览器或清除站点数据后不再保留。
- 面板可以拉宽，也可以独立成窗口。

## 保存

接口保存按 UTF-8 编解码。内容无法解析时返回明确失败，不再因为空结果把保存打成空指针。

## 接入

在业务工程中引入同版本插件：

```xml
<dependency>
    <groupId>org.ssssssss</groupId>
    <artifactId>magic-api-plugin-ai</artifactId>
    <version>2.2.2</version>
</dependency>
```

ClickHouse、Redis、Doris、SelectDB 按需增加对应的 `magic-api-plugin-*`。密钥和连接地址放在业务工程自己的配置里，不要写进本仓库。

AI 至少需要：

```yaml
magic-api:
  ai:
    enabled: true
    provider: deepseek
    api-url: https://api.deepseek.com/chat/completions
    api-key: ${MAGIC_API_AI_API_KEY:}
    model: deepseek-chat
```

# magic-api-ai 使用指南

面向二次开发同学的实用说明：如何从本仓库构建安装、在宿主 Spring Boot 项目中接入 **AI 助手**，并用通义千问（DashScope）生成、测试、发布 Magic-API 接口。

> 本仓库是 [ssssssss-team/magic-api](https://github.com/ssssssss-team/magic-api) 的 fork，在 `develop` 上已合并：
>
> - **PR #1**：Java 工具链升级为 **JDK 17–21**（字节码 `--release 17`）
> - **PR #2**：可选插件 `magic-api-plugin-ai`（Qwen / DashScope 对话生成接口）

当前版本号：**2.2.2**。

---

## 1. 项目概览

| 项 | 说明 |
|----|------|
| 基础能力 | 在线编写脚本即可映射 HTTP API，无需手写 Controller / Service / Mapper |
| 本 fork 增量 | AI 对话生成接口 + JDK 17–21 构建/运行 |
| AI 默认服务 | 阿里云百炼 DashScope OpenAI 兼容模式 |
| 默认 Endpoint | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 默认模型 | `qwen-plus` |
| 控制台入口 | `magic-api.web`（常见为 `/magic/web`） |

插件模块路径：`magic-api-plugins/magic-api-plugin-ai/`。更细的插件说明也可参考同目录下的 `README.md`。

---

## 2. 环境要求

- **JDK**：17、18、19、20 或 21（推荐 17 LTS 或 21 LTS）
- **Maven**：3.6.3+
- **DashScope API Key**：在 [阿里云百炼控制台](https://bailian.console.aliyun.com/) 创建；通过环境变量注入，**不要写入仓库**
- 字节码以 `--release 17` 编译；完整 reactor（含 `magic-api-servlet-jakarta`、`magic-api-plugin-springdoc`）需要 JDK 17+

确认本机 JDK：

```bash
java -version
# 应显示 17–21
```

## 3. 构建并安装到本地 Maven

在仓库根目录（例如你本地的 `E:\project\magic-api-ai`）：

```bash
git checkout develop
git pull

# 跳过测试，安装到本地 ~/.m2
mvn clean install -DskipTests
```

安装成功后，本地 Maven 仓库中应有：

- `org.ssssssss:magic-api-spring-boot-starter:2.2.2`
- `org.ssssssss:magic-api-plugin-ai:2.2.2`
- 以及同版本的其它 reactor 模块

> 若只想打包不安装：`mvn -DskipTests clean package`。二次开发宿主项目引用本地坐标时，请使用 `install`。

---

## 4. 宿主 Spring Boot 引入依赖

在业务项目的 `pom.xml` 中同时引入 starter 与 AI 插件：

```xml
<!-- Magic-API 核心（必需） -->
<dependency>
    <groupId>org.ssssssss</groupId>
    <artifactId>magic-api-spring-boot-starter</artifactId>
    <version>2.2.2</version>
</dependency>

<!-- AI 对话生成插件（可选，本 fork 能力） -->
<dependency>
    <groupId>org.ssssssss</groupId>
    <artifactId>magic-api-plugin-ai</artifactId>
    <version>2.2.2</version>
</dependency>
```

并确保已开启控制台（见下一节 `magic-api.web`）。

## 5. 完整 `application.yml`（Qwen / DashScope）

```yaml
server:
  port: 9999

magic-api:
  # 控制台地址：http://localhost:9999/magic/web
  web: /magic/web
  # 接口资源存储目录（按环境自行调整）
  resource:
    location: /data/magic-api

  ai:
    enable: true
    # DashScope OpenAI 兼容模式（默认）
    base-url: https://dashscope.aliyuncs.com/compatible-mode/v1
    # 强烈建议用环境变量注入，勿硬编码进仓库
    api-key: ${MAGIC_API_AI_API_KEY:}
    # 可选：qwen-plus / qwen-turbo / qwen-max 等
    model: qwen-plus
    temperature: 0.2
    timeout: 60000
    # 生成接口默认落入该分组（不存在则自动创建）
    default-group-name: AI生成
```

启动前设置 Key：

```bash
# Linux / macOS
export MAGIC_API_AI_API_KEY=sk-xxxxxxxx

# Windows PowerShell
$env:MAGIC_API_AI_API_KEY="sk-xxxxxxxx"

# Windows CMD
set MAGIC_API_AI_API_KEY=sk-xxxxxxxx
```

### 切换其它 OpenAI 兼容服务

只需改 `base-url`、`api-key`、`model`，例如：

```yaml
magic-api:
  ai:
    base-url: https://api.openai.com/v1
    api-key: ${OPENAI_API_KEY:}
    model: gpt-4o-mini
```

## 6. 打开控制台，使用 AI 助手

1. 启动宿主应用。
2. 浏览器访问：`http://localhost:9999/magic/web`（端口与 `web` 路径按你的配置）。
3. 控制台底部工具条应出现 **AI 助手**。
4. 用自然语言描述接口需求，发送后等待生成。
5. 生成成功后，接口默认保存到分组 **「AI生成」**，可继续：
   - **打开接口**：在编辑器中查看/微调脚本
   - **在线测试**：执行并查看运行日志
   - **一键发布**：调用平台资源锁定（`/resource/lock`），发布后接口不可编辑；需要修改时请先解锁

> **注意**：一键发布 = **资源锁定**。锁定后脚本只读，解锁后才可再编辑。

## 7. HTTP API

以下路径均挂在控制台前缀 `{web}` 下（例如 `{web}=/magic/web`）。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `{web}/ai/status` | 是否已配置 api-key、当前 model / base-url |
| POST | `{web}/ai/chat` | 对话生成；默认可自动保存接口 |
| POST | `{web}/ai/apply` | 将定义写入 / 更新接口 |
| POST | `{web}/ai/test` | 在线测试（复用 debug / websocket 机制） |
| POST | `{web}/ai/publish` | 一键发布（锁定） |

### `/ai/status` 示例

```bash
curl -s http://localhost:9999/magic/web/ai/status
```

关注返回中的 `apiKeyConfigured`（应为 `true`）。

### `/ai/chat` 请求示例

```json
{
  "message": "创建一个 GET /hello 接口，返回 {message:'hello magic-api'}",
  "history": [],
  "autoSave": true
}
```

```bash
curl -s -X POST http://localhost:9999/magic/web/ai/chat \
  -H "Content-Type: application/json" \
  -d "{\"message\":\"创建一个 GET /hello 接口，返回 {message:'hello magic-api'}\",\"history\":[],\"autoSave\":true}"
```

## 8. 提示词示例

可直接贴到 **AI 助手** 或 `/ai/chat` 的 `message`：

1. `写一个 GET /hello，返回 JSON：{ "message": "hello magic-api" }`
2. `创建一个 POST /user/query，请求体含 name（可选）、page、size；用 db 分页查询 user 表，按 create_time 倒序`
3. `写一个 GET /order/{id}，根据路径参数 id 查订单；查不到返回业务错误码`
4. `创建一个 POST /upload/demo，接收文件并返回文件名与大小（如环境已配置文件上传）`
5. `写一个 GET /stats/today，统计今天新建订单数，返回 { count: n }`

提示越具体（方法、路径、入参、表名、返回结构），生成质量越高。

## 9. 故障排查

### 9.1 Key 未配置 / 调用报错

- 现象：聊天失败，日志或异常提示 `magic-api.ai.api-key 未配置` / `MAGIC_API_AI_API_KEY`
- 处理：
  1. 确认环境变量已导出（或配置中心已注入）
  2. `GET {web}/ai/status` 中 `apiKeyConfigured` 应为 `true`
  3. 不要把 Key 写进 Git；重启应用使环境变量生效

### 9.2 控制台没有「AI 助手」

- 确认依赖 `magic-api-plugin-ai:2.2.2` 已进宿主 classpath（本地 `mvn clean install` 后再刷新宿主依赖）
- 确认 `magic-api.ai.enable` 不为 `false`
- 确认 `magic-api.web` 已配置且能打开控制台
- 浏览器强刷 / 清缓存后再看底部工具条

### 9.3 JDK 版本问题

- 构建或运行报编译级别 / 不支持的 class 文件版本：改用 **JDK 17–21**
- `java -version` 与 `mvn -v` 中的 Java 版本应一致（避免 IDE 与命令行 JDK 不一致）
- 本仓库要求 `--release 17`，JDK 8/11 无法完整构建

### 9.4 一键发布后无法编辑

- 这是预期行为：发布会 **锁定** 资源
- 在控制台对该接口执行解锁后，即可再次编辑

### 9.5 模型或网络超时

- 可调大 `magic-api.ai.timeout`（毫秒）
- 确认能访问 `base-url`（公司代理 / 防火墙）
- 可改用 `qwen-turbo` 等更快模型做联调
